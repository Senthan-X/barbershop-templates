# LINEWORK Studio — Barbershop V7

A precision cut-and-braid atelier with a technical editorial identity, built for the Senthan & Co Barbershop collection.

## Signature direction

- Geometric linework and drafting-grid visual language
- Ink-black, paper and signal-yellow palette
- Seven-image verified pattern library
- Interactive three-step Service Composer
- Fictional Nakasero, Kampala business details
- Thirteen unique photographs from the supplied `barbershop.zip`; no photo repeats inside V7 or overlaps the currently pushed templates

## Production standard

- One self-contained HTML file
- Base64-embedded WebP imagery
- System-aware light and dark themes with saved override
- Seven languages: English, Spanish, French, German, Portuguese, Arabic and Chinese
- Full Arabic RTL layout
- Responsive navigation, imagery and forms
- IntersectionObserver scroll reveals and reduced-motion support
- Defensive `localStorage` access
- Back-to-Top Button
- Demo-only booking form
