# Urban Cut Studio — Barbershop V3

A single-file, dependency-free barbershop template with a street-editorial identity, 36 visually verified hairstyle entries, six catalog filters, a Cut Matcher, and style-linked booking.

## Included

- 36 unique embedded WebP hairstyle images
- Six catalog filters with 12 featured styles and View All
- Cut Matcher signature interaction
- Style-to-booking linkage
- System-responsive light and dark themes with remembered override
- Seven embedded languages: EN, ES, FR, DE, PT, AR, ZH
- Full Arabic RTL layout
- Responsive navigation and full-background hero
- IntersectionObserver reveals and reduced-motion support
- Fictional demonstration contact details
- Back-to-Top Button
- Zero external runtime dependencies
